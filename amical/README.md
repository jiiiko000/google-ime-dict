# Amical（音声入力）への辞書取り込み

音声入力アプリ [Amical](https://amical.ai/) の語彙（Dictionary）に、このリポジトリの Google IME 辞書から固有名詞を取り込むためのスクリプトです。

## 仕組み

Amical の語彙には IME 辞書のような「読み・品詞」の概念がなく、SQLite（`~/Library/Application Support/Amical/amical.db` の `vocabulary` テーブル）に次の2種類で保存されます。

- **置換モード**: 文字起こし後のテキストをトリガー文字列から置換先へ文字通り置き換える
- **ヒントモード**: 単語を文字起こし時のAIプロンプトにヒントとして注入する（直近追加の200語まで）

`import_to_amical.py` は `dict/` 配下の `*_terms.txt` を再帰的に読み、次のルールで変換して DB に直接投入します（Amical のUIには一括インポート機能がないため）。

1. **品詞=固有名詞のみ対象**。日本語の一般用語（過学習 など）は Whisper がほぼ正しく書き起こすため登録しません
2. 基本は**置換モード**で登録: 読みをカタカナ化したものをトリガーに、表記へ置換（例: クバネテス → Kubernetes）
3. Amical の置換はCJKに対して**単語境界なしの部分文字列置換**のため、一般語と衝突する読みは置換にすると誤爆します（例: ゴー→Go だと「ゴール」が「Goル」になる）。こうした読みはスクリプト内の `EXCLUDE_READINGS` に列挙してあり、表記のみ**ヒントモード**で登録します

## 使い方

```bash
# リポジトリ直下で実行

# 1. 投入内容の確認（DBには書き込まない）
python3 amical/import_to_amical.py --dry-run

# 2. Amical を終了してから実行
python3 amical/import_to_amical.py
```

実行時は `amical.db` を同ディレクトリに `amical.db.bak-<日付>` として自動バックアップしてから投入します。登録済みの語（`word` 列で判定）はスキップされるので、**辞書に語を追加したら再実行すれば差分だけ追加されます**。

投入後に Amical を起動し、Settings > Dictionary で反映を確認してください。動作確認は「クバネテス」「テラフォーム」などを実際に音声入力して Kubernetes / Terraform になるかを見るのが確実です。

## メンテナンス

- **誤爆する置換を見つけたら**: その読みを `EXCLUDE_READINGS` に理由コメント付きで追加 → Amical の Settings > Dictionary から該当の置換エントリを削除 → 再実行（表記がヒントとして入り直ります）
- **ヒントモードの語の精度を上げたい**: ヒントは直近200語しかプロンプトに載らず確実性が置換より劣ります。誤認識が気になる語は、一般語と衝突しない長めのトリガーで Amical のUIから個別に置換登録してください（例: カーソルエディター → Cursor）
- DB を元に戻したい場合は、Amical を終了して `amical.db.bak-<日付>` を `amical.db` に上書きコピーします
